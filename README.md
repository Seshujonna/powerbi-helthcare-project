# PowerBI Healthcare Project

## Overview

The Healthcare.pbix file is a Power BI report designed to provide insights into healthcare data. It visualizes key metrics and trends to assist stakeholders in making data-driven decisions.

## Key Features

Patient Analysis: Provides insights into patient demographics and health conditions.

Treatment Insights: Displays data on treatments, procedures, and their effectiveness.

Financial Analysis: Visualizes cost, revenue, and billing details.

Performance Metrics: Includes KPIs such as patient satisfaction and hospital performance.
